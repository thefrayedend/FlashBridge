# Flash Bridge for Android

The phone app for a Flash Bridge board. Built by GitHub Actions (`.github/workflows/build-app.yml`,
"Build Android app"); the APK is published as the release **latest-app**.

What it does:

- **Printer** and **Slicer** tabs: the board's own web page (camera, controls, filament, Prepare / Paint / Preview).
- **Models** tab: a browser for MakerWorld, Printables, Thingiverse, Thangs. Tapping Download on a model sends it
  to the board's slicer (ZIPs: every model inside); sliced files (G-code) go to the printer.
  Double-tap the Models tab to close the open site and pick another (logins stay).
- **Open with / Share**: 3MF, STL, OBJ, ZIP and G-code from any app; a shared model-page link opens in Models.
- **Notifications** (Settings): the running print or slice in the notification bar with a progress bar (after
  Start print: sending the file %, unpacking, starting); alerts when a print finishes, pauses (also by the AI
  failure detection), fails, fails to start (the printer refused the file), or the board goes quiet mid-print;
  and when a slice is done or fails. Runs as a foreground service; starts again after a phone restart.
- Finds the board on the Wi-Fi by itself (mDNS: the board announces "FlashForge Bridge on <name>").

Layout: `lib/` is the app (Flutter). `lib/board.dart` is plain Dart and is tested against a running bridge.
`android/app/src/main/` holds what Android needs beyond Flutter: `MainActivity.kt` (files and links from other
apps, settings, multicast lock), `WatchService.kt` (notifications), `BootReceiver.kt`, the manifest and icons.
The rest of the Android project is generated by `flutter create` during the build.

Board API it uses: `/api/status` (printers, `api`, `capabilities`), `/api/slicer` (slice jobs),
`/api/slicer/inbox` (POST a model, opened by the page at `#slicer/prepare/inbox=<id>`),
`/api/printers/<id>/upload` (sliced files).

Signing: `android/app/flashbridge-sideload.jks` (password `flashbridge-sideload`) so that every build installs
over the previous one. It is public in this repo: fine for your own phones, but before sharing the app widely,
make a private key and add it as the secrets `ANDROID_KEYSTORE_BASE64` / `ANDROID_KEYSTORE_PASSWORD`
(the workflow then uses it instead). Users would have to uninstall once when the key changes.
